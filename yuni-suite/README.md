# yuni suite

Everything for the Yuni (MUHAS student app) pilot in one place.

```
brand/           Brand Suite v1 (HTML) and app icon
design-system/   tokens.css, components.css, fonts.css, demo.html
docs/            spec pack: UI, UX, system design, stack, voting, AI, security, CI/CD
```

## Start here
1. Open `design-system/demo.html` to see the components.
2. Read `docs/00-spec-index.md`, then the numbered specs.
3. Add self-hosted fonts to `design-system/fonts/` and uncomment `fonts.css`.
